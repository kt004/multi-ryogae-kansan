マルチ両替換算 プライバシーポリシー

このアプリは、あなたの情報を集めません。入力した内容は、あなたの iPhone の中だけに保存します。

項目扱い内容
個人情報の収集なし氏名、メールアドレス、位置情報などを求めません。アカウント登録もありません。
通信なしアプリの機能に通信は使いません。為替レートの自動取得もしません。
広告・行動の追跡なし広告を表示せず、利用状況の分析ツールも組み込んでいません。
第三者への提供なし開発者は入力内容を受け取らないため、第三者へ渡すこともありません。

iPhone に保存する内容

  • 通貨の名前、レート、最後に入力した金額
  • 外観、色、文字サイズの設定

アプリを削除すると、これらも iPhone から消えます。iCloud や Mac への iPhone のバックアップを使っている場合は、バックアップに含まれることがあります。バックアップの管理は Apple とご利用者の設定によります。

使い方とお問い合わせ

  • 「通貨とレートを設定」で通貨を追加し、「150 円 ＝ 1 ドル」の形でレートを入れます。
  • どの通貨の欄に金額を入れても、ほかの通貨が連動して計算されます。
  • レートは自動で更新されません。両替所やカード会社などで確認した値を入れてください。計算結果は目安です。実際の両替額は手数料などで変わります。

お問い合わせ: GitHub の Issues に書いてください（GitHub のアカウントが必要です）。

このポリシーの変更

アプリの機能が変わり、情報の扱いが変わるときは、このページを更新します。
